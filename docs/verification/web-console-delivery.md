本记录汇总 Web 0.3.0 的代码实施与本机验收；2026-10-10 已完成 Docker 生产部署，含服务器与备份位置的详细上线记录仅保留在本地。Web 重构阶段未改动桌面客户端；随后另行构建的客户端 0.2.2 仅涉及便携运行兼容与打包，详见 [客户端交付说明](desktop-0.2.2.md)；客户端性能与原生授权修复另见 [0.2.3 验收记录](desktop-0.2.3.md)。

## 交付范围

- 浅色 React 19 / TypeScript / Vite / Ant Design 6 后台，独立路由与按页加载：用户、详情、会员操作、兑换码、持久批次、工作台、版本发布、官网设置、操作记录。
- 列表默认 25 条，25/50/100、页码、跳页、总数和范围；查询状态进入 URL；同查询跨页选择，筛选/排序改变清空。手机用户列表使用完整账号摘要，详情以全屏抽屉展示。
- 单条/批量会员共享预览和提交规则：42+31 天累加、永久跳过、封禁保持、明确调整到期/撤销/封禁/解绑/冷却操作；持久 operation_id 去重，数据库版本触发器覆盖客户端兑换和旧后台变更。
- 兑换码生成结果可回访，响应丢失可重试同一批；按筛选/所选/整批导出；CSV 分块并处理公式型单元格；恢复不会激活已使用或过期的码。
- WAL 一致快照备份及恢复校验、令牌摘要拒绝、换绑事务串行化、用户字段白名单。SQLite 写处理移入同步工作线程；保留一个空闲连接稳定 WAL 生命周期。
- 官网独立重建，展示真实客户端配置截图、能力、流程、套餐联系面板、安装/便携下载、版本时间与校验值、帮助；配置缺失时入口隐藏。
- Docker 采用 Node 构建阶段与 Python 运行阶段，保持一个服务、一个数据卷、非 root/只读运行配置。旧后台 `/admin/legacy` 共用修复后的接口，可通过 `ADMIN_USE_LEGACY=true` 回退入口。

## 性能证据

Windows 11 / Python 3.12.10 / SQLite 3.49.1；1 万用户、10 万兑换码；每项 12 次暖缓存同步服务调用。基线是相同的新查询在新增索引前的结果，不是公网端到端延迟，也不作为线上承诺。

| 查询 | 索引前中位 ms | 索引后中位 ms |
| --- | ---: | ---: |
| 用户首屏 | 0.823 | 1.164 |
| 近期到期 | 2.647 | 2.635 |
| 兑换码首屏 | 2.321 | 2.367 |
| 可用兑换码 | 34.503 | 11.333 |
| 完整兑换码精确搜索 | 1.024 | 2.521 |
| 批次内兑换码 | 0.866 | 1.368 |
| 批次列表 | 9.907 | 16.046 |

批次排序查询计划从额外临时排序变为直接使用复合索引。收益集中在可用码筛选与稳定排序，部分查询增加了毫秒级成本，保留完整数据供生产规模验证。模糊包含搜索仍可能扫描表；粘贴完整码使用主键精确定位。

10 万条 CSV 共 202 块、约 5.52MB；开启 tracemalloc 的测试中耗时 2.94 秒、Python 峰值分配约 0.75MB。后台共享组件块约 827KB（gzip 268KB），Vite 给出大块提示；路由加载、传输 gzip 与带哈希静态资源长期缓存已启用。
