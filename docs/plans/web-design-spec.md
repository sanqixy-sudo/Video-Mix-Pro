## 公共组件与约束

- 主色 #2563eb；背景 #f4f6fa；表面 #fff；正文 #182238；辅助 #637087；边界 #e3e8f0。危险操作用红色文字及后果说明。
- 字体采用系统中文无衬线，正文/表格 14px、辅助最低 12px、页标题 28px；官网标题 44–64px、正文 16–18px。
- 圆角控件 8px、容器 12px；间距 4/8/12/16/24/32；浅阴影仅用于悬浮层。
- Ant Design 6 表格、表单、按钮、日期、抽屉、模态框和通知统一主题；不导入整套后台模板。
- 桌面控件高 40px；手机 44px；长账号和设备标识可换行/复制，不靠缩小字号。
- 所有列表 URL 保存查询、筛选、排序、分页；默认 25、可选 50/100；稳定唯一键排序；页码、跳页、总数和当前范围。
- 页面只加载自身 API；骨架保留结构。更新列表不重建编辑表单。错误提供重试；会话失效保留 URL 和版本草稿并返回登录。
- 详情关闭回到触发按钮；Escape 可关闭；危险操作预览说明影响，确认期间不可重复提交。

## 业务决策

续费取有效期限与当前时间较大者，加 31/93/186/366 或自定义天数；普通续费不能降级永久会员。账号封禁独立显示并保留。预览记录版本与实际计算结果，提交时检测并发变更；operation_id 的请求内容不可被替换。

兑换状态优先使用→停用→过期→可用，停用的过期码可同时显示截止时间，但恢复操作必须跳过。导出使用列表相同查询构建器，按筛选、选中码或整个批次明确区分。批次结果和去重记录保存在数据库。

## 实施顺序与验收

1. 基础修复及增量迁移：WAL 备份/恢复、令牌摘要拒绝、换绑事务、共享查询与会员服务。
2. 用户完整流程及回归：137 用户分页、42+31 天、永久/封禁/到期/并发冲突、跨页选择、可访问详情。
3. 兑换完整流程及回归：100 码幂等、过滤导出 1 条、批次回访、500 上限、状态结果。
4. 工作台、发布草稿、官网设置、真实产品截图和官网。
5. 前端类型检查/构建、后端回归、浏览器 1440/1280/390 和 200% 缩放、合成数据性能、Docker 构建启动和持久化验证。

生产数据不参与开发测试。默认北京时间展示、UTC 存储。原生客户端授权门禁仍单独修复。未提供的实际联系/下载信息由设置承接；未通过容器实测或真实开通路径的项目不得标记上线验收通过。
